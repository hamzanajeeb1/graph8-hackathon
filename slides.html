01 / What graph8 is

A programmable revenue platform.

Everything a B2B go-to-market team does, from finding a prospect to closing the deal, in one system. Every piece of it addressable by code and by AI agents.

CRM and data

Contacts, companies, deals, custom objects. 700M+ contacts to search, instant enrichment, intent and visitor signals on the record.

Outreach

Sequences across email, SMS and LinkedIn. Campaigns, newsletters, landing pages, forms. Deliverability underneath.

Voice

AI voice agents that answer, qualify and book. A power dialer. Numbers, recordings, transcripts in the CRM.

Agents and workflows

An agent runtime with skills, approvals and memory. Operator agents in the Work app. A workflow engine tying it together.

One line each. The point: it is not a CRM with an API bolted on. Every feature in the app is reachable from code, which is what makes it a backend you can build a product on.

05 / How to build on it

Two ways in. Keys at kickoff.

@graph8/sdk on npm

One npm install, typed clients for every module, plus a generated g8.api covering every published operation. React bindings included.

The Developer API

The same 3,200+ operations under one contract, any language. Scoped keys, signed webhooks, idempotent writes.

Docs: be.graph8.com/api/v1/docs · Sandbox keys and credits when your team locks an idea · Nothing leaves the building: no real sends

import { g8 } from '@graph8/sdk';
g8.init({ apiKey: process.env.G8_API_KEY });

const leads = await g8.enrich.search([
  { field: 'seniority_level', operator: 'any_of', value: ['VP', 'Director'] },
  { field: 'company_industry', operator: 'contains', value: ['SaaS'] },
]);
const list = await g8.lists.create('Hackathon ICP', 'contacts');
await g8.lists.addContacts(list.id, leads.data.map((l) => l.id));
const [seq] = (await g8.sequences.list()).data;
await g8.sequences.add({ sequenceId: seq.id, listId: list.id });
Eight lines: search 700M contacts, build a list, enrol it in a sequence. That is a working outbound motion. Everything else in the app is one call away in the same style. Mention the sandbox and the no-real-sends rule here.

07 / Rules

Six rules. Four are permissions.

✓

Code written during the weekend

Libraries, boilerplate, and templates are fine. Bring your setup, not your product.

✓

AI coding tools encouraged

Claude Code, Cursor, Codex, whatever you ship with. We build that way too.

✓

graph8 is the backend

Contacts, sequences, CRM, signals, agents, or the SDK. Use at least one surface for real.

✓

Public repo by Sunday 14:00

Public on GitHub, or shared with the graph8 org. You keep the IP. graph8 may demo it with credit.

✕

No real sends to real people

Sequences and calls run in the sandbox. Nothing leaves the building unless a mentor clears it.

✕

No spam, no scraping

Fair use rate limits apply. Hammering the search API is not a project.

Four of the six are things you are allowed to do. The two red ones are hard lines: nothing goes to a real person, and the search API is not a stress test.
